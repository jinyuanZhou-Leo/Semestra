`builtin-gradebook/` provides the course-scoped Gradebook V2 tab and summary widget.
The tab centers a Course List-style assessment workspace with percentage scores, optional points-to-percentage assessment input, category-based forecasts, persisted assessment sort preferences, and a plugin-local persisted Plan mode for What If scores plus target-format switching between GPA and GPA Percentage.
Runtime UI consumes a slim fact-only API while shared helpers derive summaries, forecasts, and plan recommendations on the client, now blocking all Gradebook math unless total assessment weight is exactly 100%, including shared TanStack Query caching reused by both the tab and settings surface, a CSS-only responsive course-only metrics widget aligned with workspace stat styling and stacked vertically to fill widget height, plugin-local one-decimal GPA-percentage display formatting via `shared.ts`, band-aware numeric-or-range GPA threshold parsing based on the matched minimum scaling-table value, and standardized semantic empty states for create and unavailable flows.
Assessment create/edit/delete flows also publish a targeted timetable refresh so Calendar can mirror any non-empty assessment due date as a gradebook source event without caring about the score field.
The add-assessment dialog also supports one-time LMS assignment import into local Gradebook rows without turning Gradebook into a synced LMS mirror, and Canvas handoff now arrives through the shared plugin host jump API instead of a custom shared event constant.
