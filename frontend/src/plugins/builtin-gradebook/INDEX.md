`builtin-gradebook/` provides the course-scoped Gradebook V2 tab, the semester-scoped course-row Gradebook view, the summary widget, and Program-scoped gradebook defaults.
The course tab centers a Course List-style assessment workspace with percentage scores, optional points-to-percentage assessment input, final-grade overrides for official course totals, category-based forecasts, persisted assessment sort preferences, and a plugin-local persisted Plan mode for What If scores plus target-format switching between GPA and GPA Percentage.
The semester tab derives credit-weighted GPA and course-level What If projections from the host-provided Semester course list without calling the course-gradebook API for every course.
Runtime UI consumes a slim fact-only API while shared helpers derive summaries, forecasts, and plan recommendations on the client, now blocking all Course Gradebook math unless total assessment weight is exactly 100%, including shared TanStack Query caching reused by both the tab and settings surface, a CSS-only responsive course/semester metrics widget aligned with workspace stat styling and stacked vertically to fill widget height, plugin-local one-decimal GPA-percentage display formatting via `shared.ts`, Program-tab-setting-backed defaults for forecast mode plus seed categories that initialize new course gradebooks, band-aware numeric-or-range GPA threshold parsing based on the matched minimum scaling-table value, continuous matching for adjacent integer-authored GPA ranges so decimal grades do not fall through 1% seams, and standardized semantic empty states for create and unavailable flows.
Assessment create/edit/delete flows also publish a targeted timetable refresh so Calendar can mirror any non-empty assessment due date as a gradebook source event without caring about the score field.
The add-assessment dialog also supports one-time LMS assignment import into local Gradebook rows without turning Gradebook into a synced LMS mirror, and Canvas handoff now arrives through the shared plugin host jump API instead of a custom shared event constant.
