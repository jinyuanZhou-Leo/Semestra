Service and registry layer for HTTP APIs, TanStack Query infrastructure, plugin registries, and app status.
Defines frontend domain contracts mirroring backend schema responses plus canonical cache keys for shared server-state resources.
Central place for retry policy, cookie-auth plus CSRF-aware HTTP defaults, semester todo APIs, runtime plugin-governance payloads, V2 tab-settings plus runtime-tab persistence, plugin-system setup contracts, query cache setup, and plugin registration rules.

| File | Role | Description |
|------|------|-------------|
| api.ts | Service module | REST gateway for program/semester/course CRUD including Program subject-color-map persistence, Program-level plugin installation governance with single and bulk enablement APIs plus typed `program_settings` writes, Program Home tab-setting persistence, unassigned-Course plugin activation read/update APIs, Semester draft-wizard lifecycle plus review endpoints with typed draft-step contracts, plugin-system setup definition/state/save/review endpoints, single and bulk Semester plugin activation enablement APIs, multi-integration LMS management, Program/Course LMS import-link-sync and LMS navigation/module-summary/module-item/page/quiz/syllabus endpoints with inline Canvas module item summaries, provider-normalized due dates plus range-filtered LMS calendar reads, ICS-backed semester/course upload imports, account-wide course-resource list/upload/link/rename/delete/download endpoints, irreversible current-user deletion, semester todo endpoints without backend-side todo reordering, persisted course colors, normalized single-shape runtime plugin-governance payloads plus API-layer-normalized runtime tab/plugin wire shapes for all runtime-tab settings/order endpoints, global user-preference updates including the active Program id, course gradebook endpoints with both percentage and optional point-based score inputs, and widget/tab contracts including force-aware widget deletion. |
| api.test.ts | Test file | Verifies that mixed backend runtime wire payloads are normalized into the single frontend `runtime` contract and that runtime-tab write endpoints return normalized tab objects. |
| appStatus.ts | Service module | Service abstraction handling app status domain logic. |
| http.ts | Service module | Axios bootstrap that applies API base URL overrides, enables credentialed cookie-auth requests, and mirrors the CSRF cookie into unsafe-request headers. |
| pluginSettingsRegistry.tsx | Service module | Registry for plugin-global settings sections plus the stable `pluginId + scope + onRefresh` settings-section contract, with cached Program/Semester/Course context snapshots, per-plugin replacement, and `useSyncExternalStore`-safe subscriptions. |
| pluginSettingsRegistry.test.tsx | Test file | Verifies plugin-global settings ordering, Program/Semester/Course context filtering, replacement behavior, and stable cached snapshot references. |
| queryClient.ts | Service module | Shared TanStack Query client singleton with app-wide query/mutation defaults for cache lifetime and retries. |
| queryKeys.ts | Service module | Canonical query-key factory used by contexts, hooks, and plugin surfaces to share cached Program plugin catalogs/installations, current Semester drafts, Semester and unassigned-Course plugin activations, Semester plugin-system setup state, gradebook, LMS integration/link, Canvas navigation/module-summary/module-item/module-file/page/quiz/syllabus browser, range-scoped LMS calendar data, semester calendar schedule windows, resource, and settings data consistently. |
| retryPolicy.ts | Service module | Service abstraction handling retry policy domain logic. |
| schedule.ts | Service module | Service abstraction handling schedule domain logic, including date-range calendar reads alongside week-based schedule APIs. |

| widgetRegistry.tsx | Service module | Runtime widget registry that stores loaded widget components, header actions, and instance settings UIs with optional course/semester context props after plugin loading, while plugin authoring now imports the public widget types from `@/plugin-system`. |
