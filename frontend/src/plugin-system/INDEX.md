Plugin manager facade for eager plugin-manifest, plugin-settings-section, and optional plugin-setup discovery, lazy runtime registration, runtime load-state tracking, workspace-local plugin-host navigation, plugin runtime instance scope, and plugin-local UI-state caching.
Bridges backend-owned plugin identity with frontend-owned manifests and setup authoring so governance UIs read `name/description/author` from APIs while the runtime still resolves plugin icons, contribution catalogs, generated setup contracts when present, and tab-to-plugin ownership locally.
Plugin System V2 now also filters host-reserved Dashboard/Settings entries out of the public plugin catalog, emits per-tab/widget allowed-context maps into the generated metadata manifest, and consumes contribution-level availability for runtime tabs/widgets.
`authoring.ts`, `host-api.ts`, `public-types.ts`, and `settings-sections.ts` now expose the stable public surfaces for plugin declarations, host/runtime helpers, unified tab/widget/settings typing, and settings-section contracts, while `index.ts` keeps discovery and HMR orchestration as the thin facade core. `pluginCatalog.ts`, `pluginLoadState.ts`, and `pluginRuntimeLoader.ts` now hold the catalog-index, load-state, and runtime-registration internals that used to live inline in `index.ts`, `contracts.ts` defines the plugin declaration helpers, including the `supportsUnassignedCourse` metadata flag that becomes backend `supports_unassigned_course`, `setup.ts` exposes the setup contract for either host-rendered DSL fields or plugin-rendered custom setup/review UI, `setupRegistry.ts` validates and serializes setup definitions, `PluginHostContext.tsx` exposes confirmed tab-jump APIs, and `PluginLoadSkeleton.tsx` provides loading skeletons plus widget-ring-matched opacity-only loading helpers. `PluginSettingsSectionRenderer.tsx` now passes a stable `pluginId + scope + onRefresh` contract through a thin shared shell so Program, Semester, and Course pages can host plugin-owned settings sections without framework-managed shared-settings persistence.
