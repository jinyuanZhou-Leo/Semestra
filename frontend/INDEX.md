Vite + React frontend for Semestra with lazy routes and plugin-driven dashboards.
This folder now owns the app-level npm manifest and lockfile for the Vite 8 toolchain, while the repository root now exposes convenience npm entrypoints that delegate to this package.
The plugin-system now exposes a workspace-local tab-jump host API so plugins can request confirmed tab switches by tab id or tab type inside the current workspace, and now also owns a frontend-authored setup DSL plus generated manifest pipeline that feeds backend plugin-system setup APIs.
Canvas-only course navigation now also lives in a dedicated builtin tab plugin that uses a compact left-side course rail, treats Canvas `default_view` as Home, keeps Assignments and Grades as first-class tab ids with native Semestra views plus a standalone Gradebook handoff card, now routes that handoff through the shared plugin host API instead of a custom window event, reads Grades from real Canvas Enrollments API data through a provider-neutral `lms/grades` frontend service call instead of local Gradebook data, still hides files/discussion tab ids, gives Announcements/Modules/Pages/Quizzes/Syllabus special views, routes unknown internal tabs and external tools to CTA-only prompt states instead of generic embeds or confirmation dialogs, keeps Canvas page links in-app, and now keeps supported Canvas module items in-app with a native detail drill-down plus locally cached native blob-backed file rendering while only External or Discussion module items still leave Semestra, all while rendering sanitized Canvas HTML safely and exposing provider-neutral Canvas navigation, module-summary, module-item, assignment, grade, announcement, page, quiz, and syllabus reads so large Canvas module lists can load item rows lazily near the viewport instead of shipping and mounting every row up front. The plugin runtime now also exposes a plugin-local UI-state cache for widget/tab UI state so transient form and toggle state can survive remounts without using backend persistence, and active semester/course tab renders now receive the same runtime instance scope as widgets.
Core behavior is split across contexts, hooks, services, reusable UI components, and a standalone `src/calendar-core/` domain layer for Calendar event-source registration.
